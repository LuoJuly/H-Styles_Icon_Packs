# H₂-Styles

Android icon pack rebuilt on [Blueprint](https://github.com/jahirfiquitiva/Blueprint) (sample branch),
currently the most used open-source icon-pack dashboard on GitHub.

| | |
|---|---|
| Application ID | `cn.luojuly.H2OS` |
| Version | 3.0.0 (17) |
| Previous dashboard | Polar (`com.afollestad.polar`) |

Open this folder in Android Studio and assemble a debug/release APK.
Requires JDK 17 and Android SDK 36.
